Learn Wen.

Wen is an experimental, Python-inspired programming language with an LLVM-based compiler that translates Wen source code into native executables.

Development status: Wen 0.2.0a1 is an experimental alpha release. Language features and compiler behaviour may change.

01. Introduction

Wen is designed around readable programming syntax and a compiler architecture that uses LLVM intermediate representation before native compilation.

Readable syntax

A Python-inspired approach to variables, conditions, loops and functions.

LLVM integration

Wen generates LLVM intermediate representation as part of its compilation process.

Native output

The compiler uses Clang to produce a native executable.

02. Getting Started

Requirements

  • Python 3.10 or newer.
  • LLVM Clang available on your system.
  • A supported environment for running native executables.

Installation

Install the current experimental release using pip:

python3 -m pip install wen-lang==0.2.0a1

Your first Wen program

Create a file called hello.wen:

let name = "Wen"

print("Hello from Wen!")
print(name)

Compile your program

wen hello.wen

The compiler generates LLVM IR and a native executable inside a build/ directory in your current working directory.

On macOS or Linux, run the generated executable with:

./build/hello

03. Language Syntax

Variables

let name = "Wen"
let version = 2
let price = 12.5

Declare variables with the let keyword.

Output

print("Hello, Wen!")
print version
print(price)

Both parenthesised and non-parenthesised print statements are supported.

Arithmetic

let a = 10
let b = 5

print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a % b)

Arithmetic operators include addition, subtraction, multiplication, division and remainder.

Conditions

let age = 20

if age >= 18 {
    print("Adult")
} else {
    print("Under 18")
}

Loops

let count = 1

while count <= 5 {
    print(count)
    count = count + 1
}

Functions

fn add(a, b) {
    return a + b
}

let result = add(10, 5)
print(result)

Booleans

let active = true
let finished = false

print(active)
print(finished)

Comments

# This is a Wen comment
let score = 100

Operators

Arithmetic: + - * / %

Comparison: == != < > <= >=

Assignment: =

Statements can be separated by newlines or semicolons. Blocks use curly braces.

04. Compiler Architecture

Wen follows a multi-stage compilation process. Source code passes through lexical analysis, parsing, semantic analysis, LLVM code generation and native compilation.

Wen Source
→
Lexer
→
Parser
→
Semantic Analysis
→
LLVM IR
→
Clang
→
Native Executable

1. Lexical Analysis

The lexer converts source characters into tokens.

2. Parsing

The parser builds an abstract syntax tree from tokens.

3. Semantic Analysis

The semantic analyzer processes the parsed program.

4. LLVM Code Generation

The code generator produces LLVM intermediate representation.

5. Native Compilation

Clang compiles the generated LLVM IR into an executable.
