THE IDEA

A script with
its own identity.

Wen Script 0.1 uses a fixed symbol for each English letter. The same input always produces the same output, and the decoder reverses the mapping.

The binary guide shows each letter's five-bit alphabet index. It is a learning aid, not encryption.

Important: Wen Script is an experimental substitution alphabet. It is not secure encryption, and this first version supports the English alphabet, digits, spaces and common punctuation.
