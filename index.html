About Wen

Wen is an evolving programming language and compiler project. Its development focuses on translating source code through compiler stages into LLVM intermediate representation and native executables.

Compiler architecture

Wen uses a structured compilation pipeline to process and translate programs.

01. Lexer

Reads source code and converts it into tokens for further processing.

02. Parser

Processes tokens and builds a structured representation of the program.

03. Semantic Analysis

Analyses program structure and checks semantic rules.

04. LLVM Code Generation

Translates supported program structures into LLVM intermediate representation.

05. Native Compilation

Uses Clang to compile generated code into native executable programs.

06. Open Development

Wen is developed openly, with its source code available on GitHub.

Your first Wen program

A simple example of a Wen source file.

hello.wen
print("Hello from Wen!")

Run the source file using the Wen command-line tool:

wen hello.wen

Get started

Install the current Wen alpha release from PyPI.

pip install wen-lang==0.2.0a1

Requirements: Python 3.10 or newer and Clang available on your system for native compilation. This is an alpha release and is still under development.
