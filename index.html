Wen is a programming language project featuring a compiler pipeline that transforms source code into LLVM Intermediate Representation and native executables.

Get Started Explore GitHub
01 / About Wen

A language with its own compiler.

Wen is an independently developed programming language. Its compiler includes lexical analysis, parsing, semantic analysis and LLVM-based code generation.

02 / Technology

Inside the compiler.

Wen uses a multi-stage compilation architecture to process programs and generate native executables.

Lexer

Transforms source text into tokens for the compiler.

Parser

Processes tokens into structured program representations.

Semantic Analysis

Checks program meaning and identifies invalid operations.

LLVM Code Generation

Generates LLVM Intermediate Representation for compilation.

Native Compilation

Uses Clang to produce native executable programs.

Command-line Interface

Install the compiler and run it through the wen command.

03 / Getting Started

Your first Wen program.

Create a file named hello.wen and write: 

print("Hello from Wen!")

Compile your program from the terminal: 

wen hello.wen
04 / Installation

Install Wen with Python.

Wen is distributed through the Python Package Index. Install the current published alpha version using pip.

pip install wen-lang==0.2.0a1

Requirements: Python 3.10 or later and Clang available on your system for native compilation.
